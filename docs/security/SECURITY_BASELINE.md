# Security baseline

Praktische leidraad: access control en least privilege, change control via reviews/migraties, logging zonder onnodige persoonsgegevens, incident- en backup/restore-procedures, asset- en leveranciersoverzicht, secure development en dependency scanning. CSP/veilige headers, sanitised errors, CSRF waar relevant, rate-limit abstraction en secure cookies worden bij productie-activatie afgemaakt. Dit is geen ISO-certificeringsclaim.
